<a id="august-11-2026"></a>
### 2026. 08. 11. { #august-11-2026 }

<a id="august-11-2026-added-features"></a>
#### 기능 추가

- 신규 리전 출시
    - 한국(평촌) 리전에 신규 출시했습니다.
- 다른 리전의 읽기 복제본 생성 기능 추가
    - 원본 DB 인스턴스와 다른 리전을 선택해서 읽기 복제본을 생성할 수 있습니다.
- 스냅숏 백업 기능 추가
    - 백업을 실행할 때 스냅숏 백업 방식을 선택할 수 있습니다.
    - Cinder 스토리지 스냅숏을 사용하여 DB 인스턴스 성능에 영향을 주지 않고 백업을 수행합니다.
- DB 엔진 신규 버전 추가
    - PostgreSQL 14.23, 17.10 버전을 추가했습니다.
- 버전 업그레이드 이력 확인 기능 추가
    - DB 인스턴스 상세 화면에서 버전 업그레이드 이력을 팝업으로 확인할 수 있습니다.

<a id="august-11-2026-feature-updates"></a>
#### 기능 개선

- 데이터베이스, 사용자 삭제 실패 처리 개선
    - 데이터베이스나 사용자 삭제에 실패하면 콘솔에 오류 메시지를 노출하도록 개선했습니다.
- 데이터베이스, 사용자 이름 길이 제한 확대
    - 데이터베이스와 사용자 이름을 최대 63자까지 생성, 수정할 수 있도록 개선했습니다.

<a id="august-11-2026-bug-fixes"></a>
#### 버그 수정

- DDL 사용자 생성 권한 미부여 문제 수정
    - 데이터베이스 직접 제어를 사용하는 상태에서 DDL 사용자를 추가할 때 생성 권한이 부여되지 않던 문제를 수정했습니다.

### 2026. 06. 09. { #june-9-2026 }

<a id="june-9-2026-added-features"></a>
#### 기능 추가

- 데이터베이스, 사용자 직접 제어 기능 추가
    - 마스터 수정 화면에서 데이터베이스, 사용자 직접 제어 옵션을 활성화하면 DDL 계정으로 데이터베이스와 사용자를 직접 생성하거나 삭제할 수 있습니다.

<a id="june-9-2026-feature-updates"></a>
#### 기능 개선

- DB 인스턴스 그룹 목록 화면 개선
    - DB 인스턴스 그룹 목록 화면의 UI, UX를 개선했습니다.
- DB 엔진 상태 반영 개선
    - DB 엔진이 중단되면 상태가 즉시 반영되도록 개선했습니다.
- pg_cron 확장 설치 후 cron 스키마 관리 기능 개선
    - pg_cron 확장 설치 후 생성되는 cron 스키마를 데이터베이스 목록에서 확인하고 직접 제어할 수 있도록 개선했습니다.

<a id="june-9-2026-bug-fixes"></a>
#### 버그 수정

- 특수 문자가 포함된 비밀번호로 사용자를 생성하지 못하는 문제 수정
    - 비밀번호에 작은따옴표(')가 포함된 경우 사용자를 생성할 수 없던 문제를 수정했습니다.
- 서비스 비활성화 시 Resource Watcher 리소스가 삭제되지 않는 문제 수정
    - DB 인스턴스가 남아 있는 상태에서 서비스를 비활성화하면 Resource Watcher에서 해당 리소스가 삭제되지 않던 문제를 수정했습니다.
- 파라미터 그룹 비교 오류 수정
    - 연결된 DB 인스턴스가 없는 파라미터 그룹을 비교할 때 오류가 발생하던 문제를 수정했습니다.

- 접근 제어 규칙 추가 기능 개선

### 2026. 02. 10. { #february-10-2026 }

<a id="february-10-2026-added-feautures"></a>
#### 기능 추가

- DB 확장 기능 추가
    - `pg_cron` 확장을 추가했습니다.
- 데이터베이스, 스키마 권한 관리 기능 추가
    - 권한이 있는 사용자만 데이터베이스, 스키마에 접근할 수 있도록 관리하는 기능을 추가했습니다.
    - DDL 권한이 있는 사용자에 한해 데이터베이스, 스키마의 소유자로 지정할 수 있습니다.
- Resource Watcher 서비스 연동
    - Resource Watcher 서비스에서 DB 인스턴스 리소스를 확인할 수 있도록 기능을 추가했습니다.

<a id="february-10-2026-feature-updates"></a>
#### 기능 개선

- 시점 복원 정보 조회 기능 개선
    - WAL 로그 파일이 많이 쌓여 있을 때의 조회 속도를 개선했습니다.
- 사용자 권한 확대
    - 읽기 전용 권한인 READ 권한을 추가했습니다.
    - DDL 권한에 대한 제약을 완화하여 추가 생성하거나, 기존 사용자 권한을 DDL로 변경하거나 삭제할 수 있습니다.

<a id="february-10-2026-bug-fixes"></a>
#### 버그 수정

- 고가용성 DB 인스턴스 접근 제어 규칙 불일치 문제 수정
    - 특정 상황에서 이전에 적용한 접근 제어 규칙이 마스터와 예비 마스터 간 불일치하던 문제를 수정했습니다.
- 삭제 불가 사용자가 삭제된 것으로 표시되는 문제 수정
    - 객체를 소유하고 있어 삭제가 불가능한 사용자가 콘솔에서는 삭제된 것으로 잘못 표시되는 문제를 수정했습니다.
    - 객체를 소유한 사용자 삭제 시 추가 옵션을 선택하여 정상적으로 삭제할 수 있도록 개선했습니다.

### 2024. 12. 10. { #december-10-2024 }

<a id="december-10-2024-added-features"></a>
#### 기능 추가

- 고가용성 기능 추가
    - 고가용성 DB 인스턴스로 생성, 수정할 수 있도록 기능을 추가했습니다.
- 데이터베이스 & 사용자 동기화 기능 추가
    - 데이터베이스 및 사용자 목록을 DB 엔진 내의 정보와 동기화해서 볼 수 있도록 기능을 추가했습니다.
- 유지 보수 설정 추가
    - DB 인스턴스의 안정화에 도움을 줄 수 있게 주기적으로 스토리지를 정리하는 기능을 제공합니다.
- 백업 내보내기 기능 추가
    - 기존 백업을 선택하거나 신규로 백업 진행 후 사용자 오브젝트 스토리지로 내보내는 기능을 추가했습니다.
- 오브젝트 스토리지에 있는 백업으로 복원 기능 추가
    - 오브젝트 스토리지로 내보낸 백업을 이용해 복원하는 기능을 추가했습니다.
- API 기능 추가
    - API로 RDS for PostgreSQL 기능을 제어할 수 있습니다.

<a id="december-10-2024-feature-updates"></a>
#### 기능 개선/변경

- DB 인스턴스 > **백업** 탭 이름 변경
    - DB 인스턴스의 상세 탭 중 **백업** 탭 이름을 **백업 및 유지 보수**로 변경했습니다.
    - DB 인스턴스 내의 유지 보수 설정을 추가로 확인할 수 있습니다.
- 데이터베이스 내 사용자 권한 변경
    - DDL 사용자 권한이 스키마 `CREATE` 권한에서 데이터베이스 `CREATE` 권한으로 확대되었습니다.
    - 권한이 확대됨에 따라 DDL 사용자 ID로 스키마를 생성할 수 있게 변경되었습니다.
- 데이터베이스 목록 조회 기능 개선
    - 데이터베이스 목록에서 DDL 사용자로 추가한 스키마 목록을 조회할 수 있게 개선했습니다.
- 백업 설정 개선
    - 백업 재시도 만료 시간 항목을 제거하고 백업 윈도우 시간 범위 내에서 백업을 재시도하도록 개선했습니다.
- 용량 확보 기능 변경
    - WAL 로그 파일을 직접 선택하는 것에서 시점 복원이 가능한 백업 시간 기준으로 선택할 수 있도록 개선했습니다.
- `shared_buffers` 파라미터 변경
    - 지나치게 큰 값을 사용하는 경우 DB 엔진 구동에 문제가 발생할 수 있으므로 DB 인스턴스 RAM 크기의 최대 50%로 제한하도록 변경했습니다.

### 2024. 10. 15. { #october-15-2024 }

<a id="october-15-2024-added-features"></a>
#### 기능 추가

- 자동 백업 설정 추가
    - 자동 백업 허용 여부를 설정하는 기능을 추가했습니다.
    - 자동 백업을 어떠한 경우에도 허용하지 않도록 설정할 수 있습니다.
        - 복제에 필요한 백업이 없는 경우 읽기 복제본 생성 작업이 제한됩니다.
- 강제 승격 시 복제 지연 대기 기능 추가
    - 강제 승격 시 복제 지연이 해소될 때까지 대기하는 기능을 추가했습니다.
- 복제 지연 대기 종료 기능 추가
    - 승격/강제 승격 시 복제 지연 대기를 종료하는 기능을 추가했습니다.
- DB 확장 기능 추가
    - `pgrouting`, `bool`, `hstore`, `intarray`, `isn`, `lo`, `ltree` 등을 설치할 수 있습니다.

<a id="october-15-2024-feature-updates"></a>
#### 기능 개선/변경

- 이벤트 구독 검색 기능 개선
    - 이벤트 소스 이름으로 검색할 수 있도록 개선했습니다.
- `shared_preload_libraries` 파라미터 입력 기능 개선
    - `shared_preload_libraries` 값 입력 방식을 다중 선택 드롭다운 목록 형식으로 개선했습니다.

<a id="october-15-2024-bug-fixes"></a>
#### 버그 수정

- 기본 알림 생성 오류 수정
    - 기본 알림 생성 시 동일한 이름의 알림 그룹이 있더라도 무시하고 생성할 수 있게 수정했습니다.
- `log_timezone` 파라미터 관련 오류 수정
    - `log_timezone` 값을 `Asia/Seoul`이 아닌 다른 값으로 적용했을 때 복제를 실패하는 문제를 수정했습니다.
- `max_connections` 파라미터 관련 오류 수정
    - 읽기 복제본이 추가된 상태에서 `max_connections` 값 변경 시 적용 순서에 따라 발생하는 문제를 수정했습니다.
    - 마스터의 값이 읽기 복제본보다 크게 설정되는 경우 파라미터를 적용할 수 없게 변경했습니다.
    - 읽기 복제본의 값이 마스터보다 작게 설정되는 경우 파라미터를 적용할 수 없게 변경했습니다.

    - 모니터링 차트 및 감시 설정에 복제 지연 항목을 추가했습니다.
- 이벤트 구독 기능 추가
    - 특정 이벤트가 발생하면 알림을 전송합니다.

#### 기능 개선/변경

- 접근 제어 기능 개선
    - 사용자 추가 시 기본 접근 제어 규칙을 추가할 수 있는 옵션을 추가했습니다.
    - 규칙 순서를 드래그 앤드 드롭으로 조정할 수 있도록 사용성을 개선했습니다.
- 파라미터 그룹 변경 사항 적용 시 실제로 변경되는 파라미터 항목을 확인할 수 있도록 개선
- 서비스 활성화 화면 개선
    - 서비스 활성화 시 자동 새로 고침되도록 개선했습니다.
- 파라미터 그룹 상세 화면 개선
    - TIMEZONE 타입을 추가하고 드롭다운으로 검색해 입력할 수 있도록 개선했습니다.
    - 단위가 있는 파라미터 편집 시 드롭다운으로 단위를 선택할 수 있도록 개선했습니다.

### 2024. 06. 11. { #june-11-2024 }

<a id="june-11-2024-release-of-a-new-service"></a>
#### 신규 서비스 출시

- Relational Database Service(RDS)는 관계형 데이터베이스를 클라우드 환경에서 제공하는 서비스입니다.
- 복잡한 설정 없이 관계형 데이터베이스를 사용할 수 있습니다.
- PostgreSQL 14.6 버전을 제공합니다.
