## Database > RDS for PostgreSQL > リリースノート

### 2026. 07. 25.

#### 機能追加

- 自動ストレージ拡張機能の追加
    - ストレージ容量不足による障害を防止できるよう、ストレージ容量を自動的に拡張する機能を追加しました。
- OSバージョンアップグレード機能の追加
    - セキュリティパッチの適用及び安定性の向上のため、DBインスタンスのOSを最新バージョンにアップグレードする機能を追加しました。
- データベース及びユーザーの直接制御機能を追加
    - マスター変更画面でデータベース及びユーザーの直接制御オプションを有効にすると、DDLアカウントでデータベースとユーザーを直接作成または削除できます。

#### 機能改善

- 高可用性DBインスタンス名入力機能の改善
    - マスターとスタンバイマスターを名前で区別できるよう、スタンバイマスターの名前も明示的に入力するように改善しました。
- ストレージ詳細チャートにログ容量収集項目を追加
    - ストレージ詳細チャートにおいて、ログ容量をデータ容量と分離して確認できるように改善しました。
- アクセス制御ルールの追加機能の改善
    - `pg_hba.conf`の記述をそのまま入力して一括追加できるように改善しました。
- DBインスタンスグループ一覧画面の改善
    - DBインスタンスグループ一覧画面のUI、UXを改善しました。
- DBエンジンの状態反映を改善
    - DBエンジンが停止した際、状態が直ちに反映されるように改善しました。
- pg_cron拡張機能のインストール後におけるcronスキーマの管理機能を改善
    - pg_cron拡張機能のインストール後に作成されるcronスキーマを、データベース一覧で確認して直接制御できるように改善しました。

#### 不具合の修正

- 記号が含まれたパスワードでユーザーを作成できない問題を修正
    - パスワードにシングルクォーテーション(')が含まれている場合、ユーザーを作成できなかった問題を修正しました。
- サービス無効化時にResource Watcherリソースが削除されない問題を修正
    - DBインスタンスが残っている状態でサービスを無効化すると、Resource Watcherで該当リソースが削除されなかった問題を修正しました。
- パラメータグループの比較エラーを修正
    - 接続されたDBインスタンスがないパラメータグループを比較する際にエラーが発生していた問題を修正しました。

### 2026. 02. 10.

#### 機能追加

- DB拡張機能の追加
    - `pg_cron`拡張を追加しました。
- データベース、スキーマ権限管理機能の追加
    - 権限のあるユーザーのみデータベース、スキーマにアクセスできるよう管理する機能を追加しました。
    - DDL権限のあるユーザーに限り、データベース、スキーマの所有者に指定できます。
- Resource Watcherサービス連携
    - Resource WatcherサービスでDBインスタンスのリソースを確認できるように機能を追加しました。

#### 機能改善

- 時点復元情報の照会機能改善
    - WALログファイルが大量に蓄積されている場合の参照速度を改善しました。
- ユーザー権限の拡大
    - 読み取り専用権限であるREAD権限を追加しました。
    - DDL権限に対する制約を緩和し、追加作成したり、既存ユーザー権限をDDLに変更または削除できるようにしました。

- 高可用性インスタンスのアクセス制御ルールの不一致問題を修正
    - 特定の状況において、以前適用したアクセス制御ルールがマスターとスタンバイマスター間で一致しなかった問題を修正しました。
- 削除不可ユーザーが削除されたと表示される問題を修正
    - オブジェクトを所有しており削除できないユーザーが、コンソールでは削除されたと誤って表示される問題を修正しました。
    - オブジェクトを所有するユーザーの削除時、追加オプションを選択して正常に削除できるように改善しました。

### 2025. 10. 28.

#### 新規サービスリリース

- Relational Database Service(RDS)はリレーショナルデータベースをクラウド環境で提供するサービスです。
- 複雑な設定なしでリレーショナルデータベースを使用できます。
